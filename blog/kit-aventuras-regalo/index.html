Cómo preparar un kit de aventuras para regalar a un pequeño lector

Alberto López

Un libro de aventuras puede ser el punto de partida de un regalo creativo y sencillo.

Elige el escenario

Pregunta si le atrae una excursión, una playa o un misterio. Escoge una historia que conecte con su respuesta y lee una muestra antes de comprarla. Usa una caja que tengas en casa para preparar el kit.

Añade tres objetos útiles

Incluye un cuaderno para pistas, un lápiz y un mapa en blanco. En una tarjeta, propone una misión: dibujar el recorrido del protagonista o inventar un lugar nuevo. Evita revelar el final del libro.

Comparte una aventura real

Ofrece una salida al parque o una visita a la biblioteca para buscar ideas. El kit puede adaptarse a un cumpleaños o a Navidad. Deja que el niño decida qué objetos utiliza y cuándo quiere leer.
