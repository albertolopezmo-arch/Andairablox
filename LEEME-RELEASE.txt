PUBLICAR APK EN GITHUB RELEASES

1. Sube el contenido de LQSA-main al repositorio, incluida la carpeta .github.
2. En GitHub abre Actions > Publicar APK en Releases > Run workflow.
3. Cuando termine, abre Releases y descarga Quiz-LQSA-prueba.apk.

Tambien se ejecuta al subir una etiqueta que empiece por v (por ejemplo v0.2.5),
o al publicar una Release desde GitHub. No necesitas subir la etiqueta para
usar la ejecucion manual: cada ejecucion manual crea una Release distinta.

El APK se publica como pre-release visible, no como borrador.
El archivo SHA256SUMS.txt permite comprobar la integridad de la descarga.
No utiliza actions/upload-artifact ni consume su cuota de almacenamiento.

IMPORTANTE: es un APK debug firmado automaticamente para pruebas, no una
compilacion de produccion para Google Play. No se ha incluido una clave privada.
Las claves debug de distintos ejecutores pueden cambiar: si Android rechaza una
actualizacion por firma incompatible, utiliza una instalacion de prueba separada
o configura una clave estable antes de distribuir actualizaciones.

Este ZIP conserva la version 0.2.5 (codigo 9) y el resto de los archivos originales.
